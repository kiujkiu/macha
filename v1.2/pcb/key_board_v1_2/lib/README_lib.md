# key_board 库 (POV3D V1.2 按键板, 2026-11-13)

- `key_board.pretty/` 4 个封装, `key_board.kicad_sym` 4 个符号, `parts.csv` 物料 + LCSC 编号, `img/` 校图。
- 封装坐标: KiCad 顶视, 原点 = 元件中心, y 向下。符号是从 KiCad 10 自带符号复制改名的, **引脚编号和自带的完全一样**, 所以原理图用自带的 `Switch:SW_MEC_5G` / `Device:LED_RAGB` / `Device:LED` / `Connector_Generic_MountingPin:Conn_01x12_MountingPin` 也能对上。
- 加载测试 (WSL kicad-cli 10.0.7): `kicad-cli fp upgrade` / `fp export svg` / `sym upgrade` / `sym export svg` 全部 rc=0。库文件就是 KiCad 自己重新存出来的版本 (fp 20260206, sym 20251024)。

## 5. 阻容
用 KiCad 自带的 `Resistor_SMD:R_0402_1005Metric` / `R_0603_1608Metric` 和 `Capacitor_SMD:C_0402_1005Metric` / `C_0603_1608Metric`, 编号见 parts.csv。**270Ω 在 0402 只有 Extended (C25099), 0603 有 Basic (C22966)**; 100Ω 和 100nF 两种尺寸都有 Basic; 68Ω/82Ω 查到的都是 Extended 或者没查到。所以建议阻容全用 0603 (原理图现在就是 0603)。

## 6. 支架让位核对 (key_bracket_v1_2.py)
让位尺寸: 本体 6.6 方 = 6 + 2×BTN_CLR 0.3 (深 3.75); 焊盘 10.1×6.2 = (9.5, 5.6) + 2×0.3 (深 LEG_DEPTH 1.5); LED 隔光孔 Φ3.2 (PL_LED_D)。两块让位都以元件中心为中心。margin = 离让位边还剩多少, 正数表示在让位里面。

| 封装 | 焊盘最外 | 焊盘 margin | 禁布区 (Courtyard) | Courtyard margin | 结论 |
|---|---|---|---|---|---|
| SW_ZX-QC66-7.5TP | ±4.75 × ±2.8 | 0.30 | 十字形: ±5.0×±3.05 加本体 ±3.25 | 0.05 | ✓ 在 6.6 方 ∪ 10.1×6.2 里 |
| LED_XL-1615RGBC | 最远 r 1.167 | 0.43 | −1.2…1.0 × ±1.0, 最远 r 1.562 | 0.038 | ✓ 在 Φ3.2 里 |
| LED_0603_A-SP192YR6AC | 最远 r 1.218 | 0.38 | ±1.4 × ±0.7, 最远 r 1.565 | 0.035 | ✓ 在 Φ3.2 里 |
| JST GH | — | — | — | — | 平板前面没有它的让位, 应放在背面 (高 4.25 ≤ BACK_MAX 6) |

- 按键的禁布区故意画成十字形, 因为矩形 10.0×6.5 在 Y 方向超出焊盘让位的 6.2。本体 6×6 离让位边还有 0.3, 本体高 3.45 对让位深 3.75。焊盘 Y 方向实际只占 ±2.8, 让位开到 ±3.1。
- 1615 / 0603 的禁布区离 Φ3.2 只剩约 0.04, 所以这两颗 LED 在板上要和隔光孔**同心**: 偏 0.04 以上禁布区就会出孔 (焊盘还有约 0.4 的余量)。
- 校图: `img/relief_fit.png` 是封装叠在让位上的图; `img/*_kicad.png` 是 `kicad-cli fp export svg --sp` (F.Cu/F.SilkS/F.Fab/F.CrtYd/F.Mask) 转出来的 PNG; `img/sym_*.png` 是 `kicad-cli sym export svg` 转出来的。
