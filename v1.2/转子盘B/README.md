## 11-19 更新 (二): 无线模块改两件对称夹块

- 用户原话: 「我们两个对称的件锁住就行 1.这个板子四个脚需要焊接线，朝上，因此红色框需要留直径3mm出口 2.pcb距离底面4mm 3，螺丝打通孔就行」
- 原一体托盘 (外墙 + 扎带) 作废 ⇒ `wireless_holder_v1_2_a` (+x) / `_b` (−x, a 的镜像): 夹块 x19.5–30.5, 顶 Z39.3; PCB 夹槽 Z34.5–36.3 (PCB 底离盘顶 4); 槽 ±y 封口挡离心。
- 四脚正上方 Φ3 直通出口 (焊好线再装); +x 件另有 Φ3 竖通道 (x27.5) 接承载盘 AC 引线孔, 盖顶横槽引到焊点。
- 每件 2×M3×8 通孔 (矮耳顶 Z35.5, 无沉孔) → 承载盘 M3×3 铜螺母 (±23, −74.5) / (±23, −34.0); 外侧耳按 r81.7 裁。
- 模块整体往 +y 挪 2.5 (y −69.5…−39)。**承载盘要重打** (无线孔 3 → 4, AC 引线孔 (21,−70)/(21,−49) → (27.5,−66.4)/(27.5,−41.4))。
- 假设待实物核: PCB 厚 1.6; 元件只在中段 |x|≤19 (两端 5 宽带无件); 脚位按底板 r1 封装推算。
