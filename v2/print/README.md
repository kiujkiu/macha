# POV3D v2 打印清单 (2026-07-13 整理)

本文件夹 = v2 (单屏配置) 整机**全部 3D 打印件**, **每零件一个子文件夹, 内含 STL (3D) + 加工图 PDF (2D)**。
13 个文件夹 / 15 个 STL, 共打 **15 件**。材料 PETG 或 ABS, 旋转件 4+ 圈壁、≥40% 填充。
整体堆叠在 `assembly/` (assembly_v2.stl + 预览图) — **仅装配核对, 不打印**。

与 v3 的区别只有 3 处 (其余 10 个文件夹与 v3/print 完全相同, 含最新版 d100):
- **gantry_base/** — 镜像左右手件 A+B 各 1 (v3 是同一件×2)
- **screen_plate/** — 单屏立板 156×192.5×6, 板背贴塔柱 (v3 是居中 176×214 + 顶舌)
- **top_cap_v2/** — L 型顶帽, 借屏顶螺母孔 (v3 是对称一字帽夹舌)
