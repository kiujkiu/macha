# POV3D V1.0 打印清单 (验证板结构, 2026-10-20)

**V1.0 = 配合验证板硬件**: ICN2260 灯板 ×2 背靠背 (缝 4.6, 夹 M3 六角铜螺母) + GW5A 桥板 ×2 + DR1M90 底板 + FS03 + WiFi。
定子 (底座三件) 和 V0.4 一样; 转子盘扩到 Φ180, 屏幕支撑、顶盖、顶轴承架、WiFi 托板都是新件。

- 全部 PLA, 单位 mm
- **STL 都是打印姿态**: 屏幕底座 (内侧面朝下)、顶盖 (顶面朝下) 已经摆好, 切片软件直接放床上就行
- 每个文件夹: STL + A3 图纸 PDF (三视图 + 孔表 + 打印姿态)
- 总册: `v1_0_print_sheet.pdf` (第 1 页总览 + 全部图纸); 打包: `pov3d_v1_0_print.zip` (不进 git, 跑 `python build_print_v1_0.py` 重生成)
- 整机装配: `assembly/assembly_v1_0.3mf` (42 个零件分开着色) —— 只用来看, 不打印

## 装配顺序要点

1. 灯板背面焊铜螺母 (A 板焊上颗, B 板焊下颗), 两板背靠背对齐
2. 顶盖: **先**从底面装光电模块的 2 颗 M3 和中心 M6, **再**把顶盖压到灯板上沿 —— 压上以后头窝就拧不到了
3. 屏幕底座 ×2 用 M3×14 锁到转子盘 (穿 rim_ring 外圈孔进 hub_disc 铜螺母), 再托住灯板下角
4. WiFi: 托板 + 罩 + 模块先用 4 颗 M3 锁成一组, 再整组拧到 4 根尼龙柱上
5. 挡光滑片锁 frame_B 臂筋, 刀片剪到筋底下 14.7
