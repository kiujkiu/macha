## 工具

- `sweep_v04.py` — 调 mtr `hss_bal.py` 跑一档/扫速, 运行时替换限速 (不改原文件); 门限; `--step 600` 两段起转 (避开 ~714 rpm 偶发 HFI 发散)。
- `phone_v04.py` — phyphox 远程访问 (http://10.10.21.228) 顶部加速度; `run` / `tap` / `amp`。手机锁屏或退后台就连不上, 测前 curl 检查。
- `phone_sweep.py` — 底 + 顶同时升速扫, 顶 3 m/s² / 底 30 mg / 顶跳 2.5× 门限。
- `tap_v04.py` — 电机不转, 底部 IMU 录敲击。`soak_win.py` — 长跑按 30 s 窗算 1×。
- 解算借 `v1.0/balance/solve_four_run.py` 的 `fit` (只用振幅的四次法)。
- 数据: `mtr/APL+LDR_V1.1/tools/_cap/hss/bal/v04_*` (手机 `*_phone.csv`)。
