## 屏幕两种装法 (2026-08-24: v4 改成居中/偏心两用)

双面屏两个 LED 面在 X=±6.7, 面上任一点到轴的最近距离就是 6.7 ⇒ 成像中心有个 **Φ13.4 盲柱**
(占屏宽 8.9%, 成像面积 0.80%)。把屏整体偏 6.7 可以让**贴轴那面盲区归零**(另一面变 Φ26.8)。

**这两种装法用同一套打印件** —— 屏支撑三件的几何都做成「同时覆盖两种落位」+ X 向 3 个离散孔,
**拧不同的孔就能切换, 不用重印**:

| | 居中 (SCR_ECC = 0) | 偏心 (SCR_ECC = 6.7) |
|---|---|---|
| 屏占位 | X −6.7..+6.7 | X 0..+13.4 |
| 中心盲区 | Φ13.4 (两面对称) | 贴轴面 **0** / 另一面 Φ26.8 |
| 用哪个孔 | `portal_tee` / `top_cap` 的 **X=0** 孔 | 两件的 **X=+6.7** 孔 |
| 罩子屏缝余量 | −X 侧 0.30 / +X 侧敞 7.00 | −X 侧敞 7.00 / +X 侧 0.30 |
| 配重臂 | **可不装** (对称) | **必装** (不平衡量 = m_屏 × 6.7) |

```
python assembly_v4.py          # 居中
python assembly_v4.py --ecc    # 偏心
```

**★ 为什么是 3 个离散孔而不是长槽**: 两个 T 件是**同件转 180°** 放的。若把锁屏孔直接挪到
(+6.7,+64), 转 180° 后第二件的孔落在 (−6.7,−64) ⇒ **两件把屏往相反方向拉, 装不上**。
顶托对称加宽 + 3 个离散孔 (−6.7/0/+6.7) 之后, 转 180° 后孔位仍是 (±6.7,−64)+(0,−64),
两件都有 +6.7 可用。用离散孔而非长槽是为了实验位置可重复。

⚠ **光电位置不跟着屏走**。模块拧在压条上, 孔位打印时就烧死在 M=(6.7,−45) 那一解上,
所以**两种装法共用同一个光电位、同一片挡光滑片**。通用解保证光轴恒过圆心 ⇒ 索引脉冲两种
装法都准; 居中装时只是「孔线中点不再落在屏顶两颗 M3 的连线上」(那是 v3.1 的外观要求,
不影响功能)。

⚠ 居中装时罩子屏缝 +X 侧会敞开约 7 mm (只是漏灰, 不影响结构)。

**换了 4 个件, 其余 10 件原样**:

| 换 | 原件 → 新件 | 为什么 |
|---|---|---|
| ✅ | `portal_tee_v3` → **`portal_tee_v3_1`** ×2 | 顶托等宽 ±16 + 3 离散孔 |
| ✅ | `top_cap_v3_1` → **`top_cap_v3_1_1`** | 条宽 18→32, 屏孔 3×2, 光电重解 |
| ✅ | `rotor_shroud_v3` A/B → **`rotor_shroud_v3_1`** A/B | 屏缝改非对称 −7.0..+13.7 |
| ✅ | `vane_slider_v3` → **`vane_slider_v4`** | 刀片外移配新光电位, 并做成左右对称 |
| ❌ | `frame_A_v4` | **不用动** —— 顶轴承架只跟柱位和轴承有关, 碰不到屏 |
| ⚠ | `frame_B_v4` | 屏改动本身不影响它; 但 2026-08-24 为了让滑片对称, 挂孔外移 2.0 ⇒ **要重印这一件** |
| ❌ | 底盘 / 两个法兰 / hub / rim_ring / wifi 壳 / 配重臂 | 全在屏以下或与屏无关 |

**代价**: 每台净增 **+16.9 g** (压条 +14.2 / T 件 ×2 +5.8 / 罩子两半 −3.0)。

校核: 两种装法各跑全对干涉 **ALL CLEAR**; 罩缝余量按坐标核对 (⚠ 快照布尔在这里会失灵 ——

## 挡光滑片改对称 (2026-08-24)

用户: 「vane_slider_v3_1 这个能做成对称的吗, 我理解 frame_A_v4 和 frame_B_v4 调整就行」。

**原来为什么不对称**: v3.1 把光电挪到 M(6.7,−45) 后刀片必须外移 δ=2.0 才不蹭, 当时为了
**不重印 frame_B** 只挪刀片、孔留原位 ⇒ 孔心 41.700 / 刀片中心 43.465, 差 **1.765**。
后果不只是难看 —— 绕竖轴翻 180° 装反时刀片落到 r38.6..41.3, **不碰任何东西但挡不到光轴**,
是个不报错的静默失效 (装上转起来就是没索引脉冲)。

**现在**: frame_B 两个挂孔外移 2.0 (36.7/46.7 → **38.7/48.7**), 刀片中心与板中心一起落到
**43.7** ⇒ 整件镜像对称, **装不反**。新件 `vane_slider_v4` (`v4/models/photo_sensor_v4/`),
件内 `SYM_C` 一个参数派生板/孔/刀片三者, 带对称性 assert。

**只重印 frame_B 一件** —— 只有 B 有这两个挂孔 (`VANE_BOLT_RS` 只作用在 `frame_b` 上),
`frame_A_v4` 重新生成后与改动前**逐字节一致**(脚本里有 cmp 校核)。滑片本身 1.1 g, 重量不变。

**校核 (全靠布尔全周扫掠, 不用径向带估)**:
- 居中 / 偏心两种装法各扫 **0.5° × 720 步 = 2160 次布尔**, 最大相交 **0.0000 mm³**
- 把刀片沿径向推着找边界 ⇒ 真实余量 **内侧 2.2 / 外侧 4.0 mm** (−2.25 与 +4.25 才开始蹭)
- ⚠ 这个实测结果和「按净通道 36.78..46.66 估」得到的 5.65/1.25 **几乎是反的** —— 又一次
  印证那条教训: 侧挂件的间隙只能扫掠, 不能拿半径带算。
- 相比原位置刀片外移了 0.235, 反而把偏紧的**内侧**余量从 1.97 加到 2.2。

## 装配顺序要点

1. **底板翻面**放好 (平面朝上, 沉孔朝下)
2. baseplate_collar_v4 居中 (**不再转 45°**), 4×M6×16 拧入 (±37.5,±37.5) 网格孔
3. flange_disc_v4 + mounting_flange_v4 + 8× M3×30+4.5mm 垫圈叠 锁紧定子
4. 电机 → hub_disc → rim_ring → pi2hub/米联派/wifi 甲板
5. 4 根柱: **M6 双头螺柱先拧进 (87.5,37.5) 族网格螺纹孔** (上螺纹胶), 再把柱旋上去坐实板面
   (柱位对比图: `../assembly/post_grid_options.png`)
6. portal_tee ×2 → 屏模组 → 压条 (M6 先装!) → 顶轴承架 + 688
7. **转子电路罩**: 在离位 ≥60mm 高度横向滑入 (屏从屏缝进) → 竖直落下 → 4× M3×12 顺沉井拧紧
   (**扣罩前先把 4 颗 M3×4×4.5 铜花螺母压进两半的配重凸台窝里**)
8. **counterweight_arm** 骑罩顶跨接缝, M3×16 ×4 拧紧 (2 颗进半A / 2 颗进半B); M6 螺栓 ×2 + Φ12 平垫叠在板上面, 按动平衡实测加配重 (⚠ 杆不许往下伸)
8. 挡光滑片按实际架高剪短刀片装上
