两种屏装法 同一套打印件 · 拧不同的孔切换

双面屏两个 LED 面在 X=±6.7，中心必然有个 Φ13.4 盲柱。把屏整体偏 6.7 能让贴轴那面盲区归零。屏支撑三件都做成「同时覆盖两种落位」+ X 向 3 个离散孔，不用重印。

居中 SCR_ECC = 0偏心 SCR_ECC = 6.7
屏占位X −6.7 .. +6.7X 0 .. +13.4
中心盲区Φ13.4（两面对称）贴轴面 0 / 另一面 Φ26.8
拧哪个孔tee / cap 的 X=0 孔两件的 X=+6.7 孔
罩缝余量−X 侧 0.30 / +X 敞 7.00−X 敞 7.00 / +X 侧 0.30
配重臂可不装（对称）必装（不平衡量 = m屏 × 6.7）

为什么是 3 个离散孔而不是长槽：两个 T 件是同件转 180° 放的。若把锁屏孔直接挪到 (+6.7,+64)，转 180° 后第二件的孔落在 (−6.7,−64)——两件把屏往相反方向拉，装不上。顶托对称加宽 + 3 个离散孔之后，两件都有 +6.7 可用。

光电位置不跟着屏走：模块拧在压条上，孔位打印时就烧死了，所以两种装法共用同一个光电位、同一片挡光滑片。通用解保证光轴恒过圆心，索引脉冲两种装法都准。

装配前必看 这些都是踩过的坑

  • 顺序
    铜花螺母要先压。罩子那 4 个配重螺母必须在扣合两半之前从罩内压入；中间轴的 M6×20 必须在压屏之前装进压条底头窝。这两步漏了就得全拆。
  • 长度
    转子罩用 M3×12，不能用 M3×14。×14 会探出 hub 底 0.5 mm 顶到电机端面。
  • 头径
    底座 4 颗必须是 M6 大扁头（头 Φ12.5）。底盘外形就是按这个头径 + 壁 3 裁出来的，换圆柱头或加平垫会顶出件外。要换先改 M6_HEAD_D/EDGE_WALL 重生成。手上若是 M6×10，穿完 5 厚底盘只剩 5 mm 旋入，偏弱。
  • 间隙
    wifi 那根插合线缆的母头扫掠到 R90.51，对柱内缘只余 0.72 mm。装机必须把这根线往内收（缩短 / 改角度 / 贴罩壁走），不能让它甩到 R>91。
  • 现场
    vane_slider 的刀片是印长的，装机按实际架高剪短，规则是刀尖距压条顶面 12 mm。打印件是全长件，直接装进去会撞压条。
  • 可选
    V4 是居中屏，理论上不需要配重，counterweight_arm 和那 4 颗 M3×16 可以不装。真要装，转速下必须防松（尼龙锁紧螺母或螺纹胶）。
  • 整机
    底板从 8.5 kg 降到 4.1 kg 对涡动是负面的（f₁≈20–27 Hz，临界 1200–1600 RPM）。强烈建议用网格板空出来的 4 个安装孔从下方把整板锁死在桌面或机架上——锁上之后比原来自由放置的重板更好。
