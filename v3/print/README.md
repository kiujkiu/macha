## 外购件 / 五金要点

- **双面屏一体模组 13.4×150×168.75 ×1** (LED 双外侧面; 底/顶面各 3×M3 通孔 居中 @64, 孔深未实测)
- **柱 Φ8×290 ×4 @ (±75,±75)** (光电叉顶 285.65 对架臂底 290 隙 4.35)
- **中间轴: M6×20 平头 + Φ8×40 单头内丝螺柱 + 688 轴承 ×2** (轴承 293..298 / 301..306;
  螺柱底坐压条顶兼锁紧; ⚠ M6 必须在压屏前装入压条底头窝)
- **光电 (2026-07-23 回归, 顶置最小方案)**: 对射模块平贴压条顶 (M3×12×2 自下经底面头窝, 螺母锁 PCB 上;
  光轴过圆心 (模块绕孔中点转 22.196°; 刀片中心 r41.7, 净通道 r36.78..46.66 余量 ~3.4/侧), 排针尾走斜置穿透避空槽, 对射脚悬空) + 挡光滑片 vane_slider_v3 锁 frame_B 45° 臂筋侧
  (2026-07-24 终版: 刀片印长 50 装机剪短补偿 M8 螺柱长度偏差; M3×20+螺母 ×2 全通孔); 模块外缘 r≈58,
  不再决定转子包络 (旧方案 r113); 索引角 ≈ 50° (45° 筋 + 侧挂偏置); 全周 5° 步进扫掠校核 ALL CLEAR
- 屏幕固定: **底 M3×12 ×2** (T 件托底向上, 帽沉 Φ7.5 让位窝) + **顶 M3×12 ×2** (压条顶向下);
  屏底/顶中央孔空置
- T 件脚: **M3×20 ×4** (T 底条 5 + 环 5 + hub ~5.5 入 hub 底铜花螺母)
- **转子电路罩: M3×12 (头 Φ7.5) ×4** —— 坐 Φ9 沉井底 3 厚台肩, 头沉在井里不露头,
  **长螺丝刀顺井 (深 47) 下去拧**; 穿 rim_ring 托盘 5 + hub 实体 1 → 拧进 hub 底既有铜花螺母
  (旋入 3.0; **M3×14 会探出 hub 底 0.5 顶到电机端面, 只能用 12**)。借 rim_ring 4 个空闲外圈
  环孔 (装配 112.5/157.5/292.5/337.5°) —— 原占这 4 孔的 ring→hub 短螺丝拆掉换成这 4 颗,
  **rim_ring 不用改**。装配顺序: 罩子在离位 ≥60mm 高度横向滑入 (屏从屏缝进) → 竖直落下 →
  拧 4 颗螺丝 (三段运动已做布尔模拟, ALL CLEAR)
- **配重 (2026-08-03 二改, 用户: "做的有点麻烦")** —— 罩子上只留 **4 个 M3 安装点**
  (半 A 2 个 @ (X−50/−72, Y+14), 半 B 2 个 @ (X−50/−72, Y−14) —— **两半关于 Y=0 镜像**),
  配重做成独立件 **`counterweight_arm`** 骑在罩顶跨接缝:
  - 罩侧: 顶板下挂 Φ9 凸台 Z43..50 + Φ4.2×4 **铜花螺母窝** + Φ3.4 过孔。
    ⚠ **M3×4×4.5 铜花螺母 ×4 要在扣半罩之前从罩内压进去**
  - 配重件: 底板 6 厚 41×38 (外缘按 R85 裁, **不超 Φ170**) + Φ16×10 M6 座 @ 力臂 r75.5;
    底面对边 10.3×4.5 六角窝卡 **M6 六角头 (朝下, 防转)**, 杆朝上穿出
  - **M3×16 ×4** 从罩外往下拧 —— 2 颗进半 A、2 颗进半 B ⇒ **本件把两半在顶部连成一体**
    (接缝原来只有各自 2 颗立柱螺丝, 这是白捡的加强)
  - **加减配重全在机器外面**: 杆上叠 Φ18×1.6 大垫圈 (2.84 g/片 = 1.78 g/mm) + 尼龙锁紧螺母,
    叠高无上限 (罩顶往上到顶轴承架 290 全空)。M6×45+14 片 = 3976 g·mm; M6×60+22 片 = 5923
  - 方向: 件在零件系 −X ⇒ 修正矢量指向 −X, 正是 v3.1 偏心屏 (+X 偏 6.7) 要抵消的方向;
    件自重 11.7 g PLA 已自带 ~751 g·mm 同向配重
  - ⚠ **转速下必须防松** (尼龙锁紧螺母或螺纹胶); v4 居中屏若不需要配重, **本件可不装**
    (装上就带 751 g·mm 偏置)
- **⚠ 罩子加了约 171 g 且几乎全在 r≈85** —— 极惯量增量很大且抬高转子 CG, **动平衡需重做**;
  v3 目前无配重挂点, 必要时用盘面空环孔
- 铜花螺母 M3×4×4.5: rim_ring 11 (7 pi2hub + 4 wifi) + d100 8; wifi 壳 M3×8 ×4;
  pi2hub 尼龙柱/网卡/电机 M3 / d100 M6 同 v2 清单; 光电暂删; 电源仍未画
- **wifi_shell 已于 2026-07-27 砍脚重出 (必须重打)**: -Y 端沿外角按盘缘 R83.5 圆弧切齐,
  装配系 r_max 90.22 → 83.50, 收进 Φ170 盘缘内; 4 颗沿螺丝孔全保留 (最外那颗 r79.06 孔周完好)
- 与 v2/print 的差异: 屏幕系统全换 (单屏门形→双面屏 T 件×2+压条), 柱 350→280,
  作废件在 `_obsolete_20260723/`
