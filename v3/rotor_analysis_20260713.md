# POV3D v3 转子受力/变形分析报告 (2026-07-13)

现象: 旋转时屏幕变形、整体偏向一边 (PLA 打印)。
几何按 assembly_v3.py / l_bracket_v3 / top_cap_v3 构建脚本核对。

## 0. 结论先行

**不是 PLA 的"强度"问题, 是系统"刚度+激励"问题。** 全部工况下 PLA 件的最大弯应力只有
1~9 MPa, 距 PLA 屈服 ~50 MPa (层间 ~25 MPa) 有 5~25 倍裕量——什么都不会断。
但结构一阶固有频率估计落在 **15~27 Hz (约 900~1600 RPM)**, 与工作转速带
5~25 Hz (300~1500 RPM) **重叠**; 残余不平衡 (尤其 wifi 盒/光电支架这些 r≈100mm
悬挂物若未精确配平) 在接近临界转速时被放大 Q≈10 倍, 表现为**同步涡动 = 转子
固定地朝重点一侧倾** —— 这正是"整体偏向一边"。

"屏幕变形"另有独立机理: 屏质心偏轴 ~6.6mm, 离心力把每块屏在上下两排螺丝之间
(跨距 147) 向外鼓出 **~1~2 mm @1500 RPM**, 与材料无关, 换塑料治不了, 要加中部固定。

## 1. 载荷计算

| RPM | ω (rad/s) | 转频 Hz | 单屏净离心力 m=0.5kg | 每颗 M3 (4颗分摊) |
|---|---|---|---|---|
| 300 | 31.4 | 5.0 | 3.3 N | 0.8 N |
| 600 | 62.8 | 10.0 | 13.1 N | 3.3 N |
| 1000 | 104.7 | 16.7 | 36.4 N | 9.1 N |
| 1500 | 157.1 | 25.0 | 81.9 N | 20.5 N |

- 双屏对称、对头螺丝在同一孔位对拉 → X 向净离心力经板体近乎抵消 (设计本身 OK)。
- 但每块屏要把 ~82N 均布载荷传到自己 4 颗角螺丝: 屏按两排螺丝间简支板
  (EI≈2 N·m², 范围1~4) → **屏中部外鼓: 600RPM 0.27mm / 1000 0.75mm /
  1500 约 1.7mm (0.9~3.4)**, ∝ω²。这是"屏幕变形"主项。
- Y 向面内张力由屏自身 PCB 承担 (<1 MPa), 无害。
- 气动: 1500RPM 板缘尖速 13.8 m/s, 单半屏阻力 0.46N, 阻力矩 ~0.10 N·m
  (气动功耗 ~15W, 电机留意); 稳态侧向力 <0.5N → 排除为主因。
- 不平衡: 10g@90mm 残差 → 1500RPM 22N; 20g → 44N。危险的是"大半径小质量"
  (sensor/wifi 盒/pi2hub 偏置), 屏重差因 r 小反而无害。

## 2. 刚度链与固有频率

- 立板整宽 I=3168 mm⁴ (EI=11.1 N·m²); **窗口段有效宽 122 → I=2196, 恰在塔顶
  (Z135.7) 之上弯矩最大处开窗 = 最薄弱截面**。
- 塔柱+满三角筋墙使 Z<135.7 段近似刚性, 塔不是短板。
- 上段悬臂 (塔顶→屏顶 L=129): k_tip ≈ 10.7 N/mm。
- **顶部定心支路是软肋**: M6 杆悬伸 66mm (k≈133 N/mm) 串联 4×Φ8×350 门架
  (钢45/铝16/打印0.8 N/mm) → 顶点横向刚度仅 5~34 N/mm; 加 2×688 径向游隙
  0.01~0.03mm ×2 + 夹舌孔隙 → 小振幅时顶约束不啮合。
- 一阶固频合成估计: **f₁ ≈ 15~27 Hz ≈ 900~1600 RPM, 横穿工作带上半段**。

## 3. "偏向一边"原因排序

1. **共振/近临界 + 残余不平衡 (主因)** — f₁ 与转频重叠; 近临界 ×Q≈10 →
   顶部挠度 mm~cm 级; 同步涡动在转子系里方向固定 → 画面固定偏一边。
2. **屏自身离心鼓包 (变形主因)** — 独立于偏摆。
3. 塔柱对角布置刚度不对称 — 180° 旋转对称保证动平衡但不保证载荷下变形对称;
   0.1~0.5mm 级, 放大"固定方向偏"。
4. 顶帽/轴承游隙 — 顶点死区 0.05~0.2mm, 死区内退化为纯悬臂 (f₁ 再降 ~30%)。
5. 气动 — 排除为主因。

PLA 角色: E 低 (3.5GPa) + 蠕变松弛 → 放大 1/3/4, 但不是断裂/屈服问题。

**先 1(配平)+2(VHB)+3i(688 波形垫圈预紧, 藏在现有堆叠内)+夹舌拧足 —— 全部零打印零外观变化;**
1500 RPM 仍偏 → 4塔对夹 (中下部) / 立板 PC 或 PA-CF 重打 (别用 PETG) / 立板翼缘。
~~3ii 柱间斜拉 / M6 套铝管~~ 已被用户否决 (顶部不加新件)。过渡: 转速 ≤850 RPM。

## 5. 锁定实验

1. **敲击测 f₁** (5min): 停转弹屏顶角, 手机 FFT; 峰在 15~30Hz 即证实共振;
   夹紧/松开顶轴承各测一次, 差值 = 顶支路贡献。
2. **升速扫频**: 300→1500 缓升, 240fps 慢动作拍屏顶对标尺; 振幅峰值转速/60 = f₁ 实测。
3. **偏向判别**: 盘缘贴反光标记, 看"偏"随标记转 (转子系固定→不平衡/结构) 还是
   对地固定 (气动/底座)。
4. **静刚度**: 百分表+弹簧秤 10N 推屏顶, 预期 3~8 N/mm; 撤力回差 >0.05mm = 游隙。
5. **称重配平量化**: 称屏/wifi盒/光电实际 m·r, 目标残差 <2 g·100mm。

关键不确定参数: 屏质量与质心偏距; 屏等效 EI (鼓包±2倍); 电机+法兰倾转刚度
(f₁±40%, 实验1 可消除); ~~4 根 Φ8 柱材质~~ **已确认: 钢 (2026-07-13 用户)** → 顶支路取上限 ~34 N/mm, f₁ 取估算带上半段 ~20~27 Hz (1200~1600 RPM); 软肋收窄为 M6 悬伸段 + 688 游隙死区, 强化优先级: 配平 > VHB > 688 预紧消隙 > (斜拉降级);
PLA 实际 E 2.5~4 GPa。
