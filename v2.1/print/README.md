# POV3D v2.1 打印清单 (2026-07-16)

v2.1 = v2 唯一改动: **四根 Φ8×350 钢柱从网格 (±125,±125) 向中心各移 1 格 (25mm) → (±100,±100)**,

## 只需要新打 3 件 (本文件夹)

| STL | 数量 | 切片姿态 | 说明 |
|---|---|---|---|
| top_bearing_frame_v2_1/frame_A_v2_1.stl | 1 | 原姿态 (正立) | 顶轴承架下半, 臂缩到 R141.42, 打印 172² |
| top_bearing_frame_v2_1/frame_B_v2_1.stl | 1 | 原姿态 (已翻转打印姿态) | 顶轴承架上半 |
| top_cap_v2_1/top_cap_v2_1.stl | 1 | 原姿态 (板顶贴床, L 腿朝上) | L 型转子帽, 配重单排 10×Φ6.5 直通 (无沉孔) @X−25, 板 53.27×144×6 (裁短+减薄 9→6); 中心 M6 头窝区切片 100% 填充 |

**其余全部零件、五金与 v2 完全相同 — 直接用 `../v2/print/` 里的文件**
(v2 的 frame_A_v2 / frame_B_v2 / top_cap_v2 三件在 v2.1 中作废, 别装错)。

注意: 配重力臂 46→25 意味着同样的不平衡量需要 **约 1.8 倍的配重质量**,
调平时垫片/螺母用量会比 v2 多, 但每格调整更细。

间隙核对: 转子最大回转半径 ~114.7 (光电支架外角) vs 柱内缘 137.4 → 留 22.7。
柱内移使顶架臂缩短 ~20%, 顶部支路刚度提高 (对旋转偏摆有小幅改善)。

整体堆叠在 `assembly/` (assembly_v2_1.stl + 预览) — 仅核对, 不打印。
